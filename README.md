# Piano Tiles – Custom

Ein einfaches, browserbasiertes Piano-Tiles-Spiel im Stil bekannter Mobile-Games, mit eigenen Hintergründen, Morph-Übergängen und Song-Auswahl.

## Spielen

### Lokal

Einfach `index.html` im Browser öffnen – fertig. Kein Build, keine Dependencies.

### Online via GitHub Pages

1. Im Repo: **Settings → Pages**
2. Source: `Deploy from a branch`
3. Branch: `claude/piano-game-custom-content-4qchb` · Folder: `/ (root)`
4. Nach ca. einer Minute ist die Demo unter `https://<user>.github.io/pianogame/` erreichbar.

## Steuerung

- **Maus / Touch:** Kacheln an der Hit-Line antippen
- **Tastatur:** `A S K L` für die vier Spuren

## Features

- 20 Songs: klassische Public-Domain-Stücke, Ragtime und eigene Kompositionen (Synthwave, Chiptune, Lo-Fi, EDM, Ambient)
- 12 Preset-Hintergründe + eigene Bilder (Upload, lokal im Browser gespeichert)
- 8 Morph-Übergänge mit Auto-Wechsel in einstellbarem Intervall
- Frei wählbare Kachelfarbe & Glow
- Geschwindigkeit 0.5× – 2.5×
- Web-Audio-Synthesizer – keine externen Sound-Dateien nötig

## Hinweis zum Urheberrecht

Alle enthaltenen Melodien sind entweder gemeinfrei (Public Domain) oder eigens für dieses Projekt komponiert. Moderne Pop-Songs wurden bewusst nicht aufgenommen, da ihre Melodien urheberrechtlich geschützt sind.
